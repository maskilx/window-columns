# Window Columns 0.1.0 Beta 1

This is the first public beta of Window Columns, a native, open-source macOS app
that turns selected windows into connected full-height column groups.

## Highlights

- Give each window group its own Dock and Command-Tab entry.
- Resize connected columns by dragging the divider between them.
- Snap displaced windows back into place or drag across a column centre to swap.
- Minimize and restore an entire group while unrelated groups keep working.
- Save group names, window order, proportions, display, gap, and shortcuts.
- Run entirely on the Mac with no telemetry, analytics, or network service.

## Install

Download `Window-Columns-v0.1.0-beta.1.zip`, extract it, and move
**Window Columns.app** to `/Applications`.

The attached beta is ad-hoc signed and **not notarised by Apple**. macOS will
warn on first launch. Review the source and verify the attached SHA-256 checksum
before running it. You can also build directly from the tagged source using the
instructions in the README.

Window Columns requires macOS 13 or later and Accessibility permission. Window
previews additionally require optional Screen Recording permission. The beta has
been used on macOS 26 on Apple silicon but has not yet been tested across the
full supported range.

Please report reproducible problems through the repository's bug-report form and
report vulnerabilities privately through GitHub Security Advisories.
