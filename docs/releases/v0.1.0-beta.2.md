# Window Columns 0.1.0 Beta 2

This is the second public beta of Window Columns, a native, open-source macOS app
that turns selected windows into connected full-height column groups.

## Highlights

- **Modern Acrylic Chooser**: Completely redesigned window switcher featuring frosted acrylic glass (`.ultraThinMaterial`), squircle cards, and stationary bounds that eliminate layout jitter.
- **Fixed Display-Aware Sizing**: Rock-solid modal bounds tailored to your display (`720×560pt` for laptops, `920×680pt` for external monitors).
- **Interactive Live Column Preview**:
  - Drag and drop columns to reorder physical pane positioning with live drop target feedback.
  - Drag cyan divider split handles with `<->` cursor to customize column split widths in real time, accompanied by live percentage metrics.
  - Quick shift chevrons (`‹` / `›`) and a one-click `[↺ Reset Equal]` button.
- **Multi-Group Visual Markers**: Windows belonging to one or more groups display color-coded pills (`● GroupName`) and group-tinted outlines across cards.
- **Single-Word AI Group Naming**:
  - Automated workflow powered by Google Gemini 2.0 Flash REST API.
  - Smart local offline heuristic fallback when no API key is provided or when offline.
  - Interactive approval review card with individual `[✓ Accept]` / `[✕ Reject]` buttons and `[Apply All]`/`[Discard]`.
  - Secure API key settings field with direct link to Google AI Studio.
- **Classic Mode Toggle**: The original switcher design is 100% preserved and switchable in Settings and Chooser header menu.
- **Stability & Performance**:
  - Fixed group minimization restoration when switching via Command-Tab.
  - Automatically dismiss chooser when clicking outside on another application.
  - Synchronized live window divider overlay positioning during window resize.
  - Real-time card badge reactivity upon group rename or deletion.
  - Background task cancellation safeguards on modal close preventing orphaned network requests.

## Install

On an Apple silicon Mac, download
`Window-Columns-v0.1.0-beta.2-macos-arm64.zip`, extract it, and move
**Window Columns.app** to `/Applications`. The prebuilt beta is arm64-only;
Intel Mac users should build from source.

The attached beta is ad-hoc signed and **not notarised by Apple**. macOS will
warn on first launch. Review the source and verify the attached SHA-256 checksum
before running it. You can also build directly from the tagged source using the
instructions in the README.

Window Columns requires macOS 13 or later and Accessibility permission. Window
previews additionally require optional Screen Recording permission. The beta has
been used on macOS 26 on Apple silicon but has not yet been tested across the
full supported range.

Please report reproducible problems through the repository's bug-report form and
report vulnerabilities privately through GitHub Security Advisories.
