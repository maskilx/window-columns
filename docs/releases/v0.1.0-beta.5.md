# Window Columns 0.1.0 Beta 5

This beta improves minimization, preserves custom column proportions when group membership changes, and selects update downloads for the Mac's architecture.

## Improvements

- **Minimize several windows safely.** Rapid or simultaneous minimization removes all minimized members before rearranging the remaining columns. Minimizing every member dismantles the group without writing new frames to those windows.
- **Keep custom proportions.** Closing a member or moving it into another group preserves the relative widths of the remaining columns. Closing a selected member also updates the active selection before applying the new layout.
- **Compatible update downloads.** The updater selects an Apple silicon or Intel asset matching the running build, or a universal binary. It no longer offers an unrelated ZIP, an empty asset, or an incompatible architecture. When no compatible binary exists, the release page remains available for source installation instructions.

## Validation

Regression coverage includes batch minimization, closing a middle column, regrouping with unequal column widths, and update asset selection. The release workflow runs the full build and regression suite, then verifies the packaged application signatures and architecture.

## Install or upgrade

Download `Window-Columns-v0.1.0-beta.5-macos-arm64.zip`, extract it, quit the previous version, and replace **Window Columns.app** in `/Applications`.

The prebuilt beta requires an Apple silicon Mac, macOS 13 or later, and Accessibility permission. Intel users should build from source. The binary is **ad-hoc signed and not notarised by Apple**; if Gatekeeper blocks it, use **System Settings → Privacy & Security → Open Anyway** after verifying the download.

Download the accompanying checksum file into the same directory and run:

```sh
shasum -a 256 -c Window-Columns-v0.1.0-beta.5-macos-arm64.zip.sha256
```

For Homebrew installations, after the cask update is published:

```sh
brew update
brew upgrade --cask maskilx/window-columns/window-columns
```

Please include the macOS version, affected applications, group membership, and reproduction steps when reporting an issue.
