# Window Columns 0.1.0 Beta 4

This beta improves window-group activation, minimization, and layout stability, and adds adjustable padding around groups.

## Highlights

- **Reliable Command-Tab activation.** Groups containing multiple windows from the same app now bring all members forward while preserving the intended focused window. Activation avoids unnecessary resizing and repeated focus changes that could cause shaking.
- **Predictable minimization.** Minimizing a group can reveal an ungrouped window from the same app. Background groups no longer steal focus when minimized, and the minimize shortcut targets the focused group. Restoring a group leaves unrelated minimized windows alone.
- **Screen-edge padding.** Set 0–64 pt of padding in Settings → General → Layout, independently of column gaps. The preference is saved and reflected in chooser previews; it applies immediately to the current group and to other groups when activated.

## Reliability improvements

- Cancel delayed group activation when switching to another app or an unrelated window in the same app.
- Keep identically titled, overlapping windows distinct during discovery.
- Preserve saved group membership when an Accessibility scan temporarily misses a window.
- Cancel obsolete divider writes when selection changes and prevent resize feedback loops.
- Serialize companion launches and handle stale callbacks, shutdown, and crash retries consistently.
- Normalize duplicate saved group IDs and enforce the nine-group limit.

## Validation

The release includes coordinator regression tests for same-app groups, minimization, activation cancellation, padding, persistence, and divider writes, alongside core checks and live window stacking and geometry checks.

## Install or upgrade

On an Apple silicon Mac, download `Window-Columns-v0.1.0-beta.4-macos-arm64.zip`, extract it, and move **Window Columns.app** to `/Applications`. Quit the previous version before replacing it. macOS 13 or later and Accessibility permission are required. Intel users can build from source.

For Homebrew installations, once the cask update is available:

```sh
brew update
brew upgrade --cask maskilx/window-columns/window-columns
```

The binary is **ad-hoc signed and not notarised by Apple**. If Gatekeeper blocks it, use **System Settings → Privacy & Security → Open Anyway** after verifying the download.

Download the accompanying `.sha256` file into the same directory as the ZIP and verify it before installing:

```sh
shasum -a 256 -c Window-Columns-v0.1.0-beta.4-macos-arm64.zip.sha256
```

Please report reproducible issues with the affected apps, macOS version, group membership, and steps to reproduce. Report security vulnerabilities privately through GitHub Security Advisories.
