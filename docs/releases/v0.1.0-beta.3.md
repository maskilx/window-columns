# Window Columns 0.1.0 Beta 3

This is the third public beta of Window Columns, introducing in-app updates, Gatekeeper resolution across all distribution channels, a dynamic full-color menu-bar icon, and light mode UI/UX refinements.

## Highlights

- **Native "Check for Updates"**:
  - Direct integration with GitHub Releases API without any third-party dependencies.
  - Built-in SemVer 2.0 comparator handling stable and prerelease precedence.
  - Interactive Software Update dialog showing release notes, direct asset download, and Homebrew cask upgrade instructions.
  - Available in Menu Bar context menu, Chooser gear menu, and Settings (General tab) with automatic background checking.
- **Dynamic Full-Color Menu Bar Icon**:
  - Replaced wireframe icon with the high-resolution application Dock icon (`AppIcon-v3-Dark` / `AppIcon-v3-Light`).
  - Automatically switches between Dark and Light appearances in real time with Retina sharpness.
- **Gatekeeper Resolution Across Distribution Channels**:
  - Automatic `postflight` unquarantine hook in Homebrew Cask (`Casks/window-columns.rb`) to open out of the box without Gatekeeper warnings.
  - In-app `QuarantineRemover` to automatically strip quarantine flags from the main bundle and all 9 companion helper apps upon first launch.
  - Apple Hardened Runtime entitlements and codesign support for Developer ID notarization (`Scripts/notarize.sh`).
  - Added `make unquarantine` command to `Makefile`.
- **Light Mode UI/UX Polish**:
  - Redesigned the Live Column Preview dock with an appearance-adaptive translucent tray and high contrast.
  - Replaced raw neon cyan text with a crisp macOS accent status pill (`Col 1: 50% · Col 2: 50%`).
  - Switched column cards to elevated cards with hairline strokes and soft depth shadows.
  - Upgraded interactive column divider handle to native macOS accent blue with smooth hover animation.

## Install

### Homebrew Cask (Recommended)

```sh
brew tap maskilx/window-columns https://github.com/maskilx/window-columns
brew install --cask maskilx/window-columns/window-columns
```

### Prebuilt Binary

On an Apple silicon Mac, download `Window-Columns-v0.1.0-beta.3-macos-arm64.zip`, extract it, and move **Window Columns.app** to `/Applications`. The prebuilt beta is arm64-only; Intel Mac users should build from source.

The attached beta is ad-hoc signed and **not notarised by Apple**. If Gatekeeper presents a warning:
1. Click **Open Anyway** in **System Settings → Privacy & Security**; or
2. Run `xattr -cr "/Applications/Window Columns.app"`.

Verify the attached SHA-256 checksum before running:
```
7b05283dc2f586ede3aed1aff4d6cfa8f2d599dc3aabed2e8e276b785b3a4ea3  Window-Columns-v0.1.0-beta.3-macos-arm64.zip
```

Window Columns requires macOS 13 or later and Accessibility permission. Please report reproducible problems through GitHub Issues and vulnerabilities privately via GitHub Security Advisories.
